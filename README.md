# deBricks website

A refreshed, responsive static website for deBricks LLP.

- `index.html` contains the page content.
- `styles.css` contains the visual design and responsive layouts.
- `script.js` handles the mobile menu, sticky navigation and WhatsApp enquiry form.
- `assets` contains selected brand imagery and client logos from the previous site.
- `old` preserves the archived website source and is not included in deployment builds.
- `dist` is generated by `npm run build` and is ready to upload to Namecheap `public_html`.

See `DEPLOYMENT.md` for deployment steps.

Website repository for **bricksmarketing.com** and **debricks.com**.

## Overview

This repo holds the source for two related sites:

- **bricksmarketing.com** — legacy Bricks Marketing domain
- **debricks.com** — deBricks

## Getting Started

Clone the repo:

```bash
git clone https://github.com/jimjwong/debricks_website.git
cd debricks_website
```

Setup and build instructions will be added once the site tooling is in place.
